# Topic 03: Cargo Basics 📦

## 🎯 Brief Overview
Cargo is Rust’s official build system and package manager. It downloads your library dependencies, compiles your code, creates distributable packages, and uploads them to `crates.io` (the Rust community’s package registry). It is universally standardized; every Rust developer uses the exact same build tool.

---

## 🧠 Critical Technical Insights
> [!IMPORTANT]
> * **The Manifest (`Cargo.toml`):** This is where you define your project metadata, dependencies, and build profiles. It is written in TOML (Tom's Obvious, Minimal Language).
> * **The Lockfile (`Cargo.lock`):** Automatically generated by Cargo. While `Cargo.toml` says "I need version 1.x of this library," the `Cargo.lock` file pins the *exact* micro-version downloaded (e.g., 1.4.2) to guarantee reproducible builds across any machine. **Never manually edit this file.**
> * **Build Profiles:**
>   * `dev` (Default): Used for `cargo build` or `cargo run`. Compiles fast, includes debug symbols, but the binary is slow.
>   * `release`: Used via `--release`. Takes much longer to compile (applies heavy optimizations), strips debug info, and produces blazing-fast, production-ready machine code.

## 💻 Essential Commands Reference

| Task | Command | Purpose |
| :--- | :--- | :--- |
| **New Project** | `cargo new <name>` | Creates a new directory with a standard Rust project skeleton. |
| **Check Code** | `cargo check` | Compiles your code to check for errors *without* generating a binary. (Blazing fast, use this 90% of the time during development). |
| **Build Debug** | `cargo build` | Compiles the project and outputs an unoptimized binary in `./target/debug/`. |
| **Run Project** | `cargo run` | Compiles the code and immediately executes the resulting binary. |
| **Add Library** | `cargo add <crate>` | Automatically fetches a library from `crates.io` and adds it to `Cargo.toml`. |
| **Build Prod** | `cargo build --release`| Compiles a highly optimized binary into `./target/release/`. |
